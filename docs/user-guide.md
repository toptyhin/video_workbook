# Руководство пользователя

## Добавить папку и проиндексировать

1. Левая панель → «Файлы» → «Добавить папку» (или кнопка **＋ В анализ** в тулбаре — выбрать файлы/папку).
2. Приложение просканирует папку, определит длительность и покажет файлы в списке.
3. Отслеживаемые папки наблюдаются: новые видео появляются автоматически.

## Транскрипция

Двойной клик по файлу → панель предпросмотра. Если транскрипции нет — «Обработать сейчас». Очередь FIFO, прогресс виден в статусе.
Модель и язык — в настройках (`small` по умолчанию, CPU INT8). Отмена — «－»/контекстное меню/статус.

## Поиск

- Поле поиска в тулбаре: обычные слова, фразы в кавычках, `AND`/`OR`/`NOT`.
- `tag:имя` — поиск по тегу, `file:имя` — по имени файла.
- Переключатель области: Везде / Файлы / Сегменты / **Метки**.
- Клик по результату-сегменту или метке открывает видео на нужном таймкоде.

## Теги

Таб «Теги» в левой панели: создать/переименовать/удалить, иерархия до 5 уровней, счётчики. Перетащите тег на файл в списке,
чтобы назначить. Ctrl+клик — мультивыбор (объединение/пересечение в настройках). Экспорт/импорт — JSON.

## Метки на видео (ручная разметка)

- **＋ метка** в панели таймингов — метка на позиции плеера; `Ctrl+M` — то же (или на выделенном диапазоне строк).
- **Перетащите по таймлайну** — метка на диапазоне (snap к 1 с/границам сегментов; Alt отключает).
- Выделите строки таймингов → «Создать метку» — несколько меток за раз.
- В диалоге: начало/конец (таймкоды), название, цвет, теги, заметка. Валидация: конец позже начала, минимум 0,3 с.
- Маркеры на таймлайне: клик — переход, двойной клик — правка, правый клик — меню (правка/цвет/удалить/копировать таймкод).
- Границы метки перетаскиваются ручками на таймлайне; изменения сохраняются на отпускании.
- `Delete` — удалить выбранную метку, `Ctrl+Z`/`Ctrl+Shift+Z` — отменить/повторить.
- Панель «Метки» — все метки библиотеки с фильтрами (текст/тег/цвет/видео), экспорт/импорт JSON.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+F` | фокус в поиск |
| `Ctrl+O` | добавить файлы |
| `Ctrl+M` | новая метка |
| `Shift+I` / `Shift+O` | начало/конец метки в позиции плеера |
| `Space` | play/pause |
| `←`/`→` | ±5 с |
| `J`/`K`/`L` | −10 с / play-pause / +10 с |
| `Delete` | удалить выбранную метку |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / повторить |
| `F1` | окно «О клавишах» |
| `Esc` | закрыть/очистить |
