# Задача для агента: разработка локального приложения «VideoLessons»

## 0. Миссия

Создать десктопное приложение под Ubuntu (GNOME, 2026), которое позволяет:
- индексировать папки с видеоуроками,
- автоматически транскрибировать их локально (CPU, без сети),
- искать по произнесённым словам,
- просматривать видео с синхронизированной панелью таймингов,
- назначать пользовательские теги и метки на фрагменты видео.

Приложение должно упаковываться в единый установочный файл (`.deb` + `.AppImage`) и запускаться двойным кликом без установки Python, ffmpeg или моделей пользователем.

## 1. Технический стек (зафиксирован, не менять без обоснования)

| Слой | Технология |
|---|---|
| UI-оболочка | Electron 31+, electron-builder |
| Бэкенд | Python 3.11, FastAPI, uvicorn, `faster-whisper` (INT8, CPU), `ffmpeg` (sidecar-бинарник) |
| БД | SQLite + FTS5 + `sqlite-vec` (опционально) |
| Frontend | Vite + TypeScript + React (или vanilla, на усмотрение агента) |
| Упаковка | PyInstaller `--onedir` для бэкенда → `extraResources` в electron-builder |
| Целевая ОС | Ubuntu 22.04+, x86_64 |

### 2.1. Верхняя панель инструментов (Toolbar)

- **`＋ В анализ`** — добавить выбранные файлы/папку в очередь обработки (диалог выбора файлов + drag&drop на список).
- **`－ Из анализа`** — удалить из индекса (с подтверждением; файл на диске не трогать).
- **Поле поиска** с debounce 300 мс, Enter — принудительный поиск, Esc — очистка.
  - Обычный запрос — FTS5 по сегментам транскрипции и по названиям файлов.
  - Префикс `tag:` — поиск по тегам; префикс `file:` — только по именам.

### 2.2. Левая панель (переключается двумя табами)

**Таб «Файлы»** — дерево файловой системы:
- Показывает только папки, которые пользователь явно добавил в «отслеживаемые» (кнопка «Добавить папку» в контекстном меню или в настройках).
- Раскрытие → подгрузка дочерних папок.
- Клик по папке → правый список показывает файлы этой папки (без рекурсии).
- Иконка статуса рядом с папкой: сколько файлов обработано / всего.

**Таб «Теги»** — иерархическое дерево пользовательских тегов (аналог digiKam):
- Иерархия: `Учёба → Математика → Производные` (поддержка вложенности через `parent_id`).
- Рядом с тегом — счётчик файлов.
- Клик по тегу → список файлов с этим тегом (и с дочерними тегами).
- Правый клик: Создать / Переименовать / Удалить / Экспортировать.
- Drag тега на файл в списке → назначить тег.
- Мультивыбор тегов (Ctrl+клик) → пересечение или объединение (переключатель в настройках, по умолчанию «объединение»).

Ширина панели — перетаскиваемая, состояние сохраняется.

### 2.3. Центральная верхняя панель — «Список файлов»

Таблица с колонками:
| Файл | Длительность | Статус | Теги | Дата изменения |

- **Статус**: `Не обработан`, `В очереди`, `Обработка N%`, `Обработан`, `Ошибка: <текст>`.
- **Сортировка** по любой колонке.
- **Мультивыбор** (Ctrl/Shift), выделение влияет на кнопки `＋/－ В анализ` и контекстное меню (назначить тег, удалить, открыть в проводнике, переобработать).
- **Двойной клик** → загрузить в нижнюю панель предпросмотра.
- **Правый клик**: назначить/снять тег, скопировать путь, «Переобработать», «Удалить из индекса».
- Пустое состояние: подсказка «Выберите папку слева или добавьте файлы в анализ».
- Если активен поиск — сверху строка «Найдено N результатов по запросу "…" [×]».
- Если открыт файл — строка выделена.

### 2.4. Центральная нижняя панель — «Предпросмотр»

Состоит из трёх частей:

**Слева — видео-плеер** (`<video>` элемент):
- Управление: play/pause, перемотка ±5с, громкость, полный экран.
- Горячие клавиши (когда в фокусе плеер): Space, ←, →, J/K/L.
- Время воспроизведения крупным шрифтом.

**Снизу плеера — таймлайн** (canvas или `<div>` overlay):
- Визуализация длительности.
- **Фоновые полупрозрачные блоки** — сегменты транскрипции (цвет по умолчанию — синий 15% opacity, tooltip = текст сегмента).
- **Цветные маркеры** — пользовательские метки (см. панель таймингов).
- Клик по таймлайну → seek. Перетаскивание ползунка — скраббинг.

**Справа — панель «Тайминги»** (скроллируемый список):

Каждый элемент — сегмент транскрипции с временной меткой:
```
[00:12]  Введение в тему
[00:48]  Сегодня мы разберём...
[01:45]  Основные понятия
```

- **Клик по строке** → seek к началу сегмента + подсветка строки.
- Во время воспроизведения **активный сегмент автоматически подсвечивается** и прокручивается в видимую область (`scrollIntoView({block:'nearest'})`).
- **Выделение мышью диапазона строк** → кнопка «Создать метку» (или Ctrl+M).
- **Метки пользователя** отображаются в этом же списке, но с цветным фоном и иконкой 🏷, между/поверх сегментами в хронологическом порядке.
- **`＋ метка`** в шапке панели → создать метку на текущей позиции плеера (диалог: начало, конец, название, цвет, теги, заметка).
- Метка кликабельна: клик → seek на её начало; двойной клик → редактировать.
- Правый клик по сегменту → «Скопировать текст», «Перевести» (опционально, за фичефлагом).
- Если транскрипции нет — панель показывает «Транскрипция ещё не готова» с кнопкой «Обработать сейчас».

**Раскладка:** панель таймингов сворачиваемая (кнопка «◀/▶» на её краю), ширина перетаскиваемая, состояние сохраняется в `localStorage`.

## 3. Функциональные требования

### 3.1. Управление библиотекой
- Пользователь указывает одну или несколько корневых папок в настройках; они добавляются в `watchdog`-наблюдатель.
- Новые видеофайлы в отслеживаемых папках появляются в списке со статусом «Не обработан».
- Поддерживаемые форматы: `mp4, mkv, mov, avi, webm, m4v` (через ffprobe).
- Дедупликация по `sha256` — повторно не индексировать.
- «Удалить из индекса» не удаляет файл с диска, но удаляет транскрипцию, сегменты, метки.

### 3.2. Транскрипция
- Воркер работает в отдельном процессе (не блокирует UI).
- Модель: `faster-whisper`, `small`, INT8, `cpu_threads=6`, `vad_filter=True`, `word_timestamps=True`.
- Язык определяется автоматически, с возможностью форсировать в настройках (ru/en по умолчанию для русскоязычных уроков).
- Очередь: строго последовательная, FIFO. В UI отображается прогресс по текущему файлу и длина очереди.
- Прогресс — через `websocket` или `SSE` (агент выбирает SSE — проще).
- Отмена: пользователь может убрать файл из очереди до старта или прервать текущий процесс.
- Ошибки (ffmpeg упал, файл битый) — сохраняются в `videos.error`, статус `error`, лог в файл.

### 3.3. Поиск
- Ввод в поле сверху → debounce → запрос к `GET /api/search`.
- Результаты: файлы, где найдено; фрагменты (сниппеты) с подсветкой `<mark>`; при клике на сниппет — видео открывается и seek на `start_ms`.
- Если поиск пуст — показывается текущий контекст (папка/тег).
- Поддержка операторов FTS5: `AND`, `OR`, `NOT`, фразы в кавычках. Префикс `tag:` и `file:` — см. 2.1.

### 3.4. Теги
- Иерархические, произвольная глубина (ограничение UI — 5 уровней).
- Назначаются как файлам, так и **отдельным сегментам/меткам** (у сегмента могут быть теги — например, «важное», «ошибка»).
- Цвет тега — необязательный атрибут.
- Импорт/экспорт тегов в JSON.

### 3.5. Метки (annotations)
- Метка = `{video_id, start_ms, end_ms, label, color, note, tag_ids[]}`.
- Создание: выделением на таймлайне, выделением строк в панели таймингов, кнопкой `＋ метка`.
- Редактирование: изменениe `start/end` перетаскиванием на таймлайне; изменение текста — inline в панели.
- Удаление — через контекстное меню или клавишу Delete на выделенной метке.

### 3.6. Настройки (модальное окно)
- Отслеживаемые папки (добавить/удалить).
- Модель Whisper (`tiny/base/small/medium`) с предупреждением о скорости.
- Язык транскрипции (auto/ru/en).
- Тема оформления (light/dark/system).
- Кнопка «Переиндексировать всё» и «Очистить кэш моделей».

### 3.7. Горячие клавиши
- `Ctrl+F` — фокус в поиск.
- `Ctrl+O` — добавить файлы в анализ.
- `Ctrl+M` — создать метку на текущей позиции / выделенном диапазоне.
- `Space` — play/pause (если фокус в плеере или панели таймингов).
- `Ctrl+1..9` — переход к первым N сегментам (опционально).
- `F1` — окно «О клавишах».

## 4. Модель данных (SQLite)

```sql
CREATE TABLE videos (
  id INTEGER PRIMARY KEY,
  path TEXT UNIQUE NOT NULL,
  title TEXT,
  duration_ms INTEGER,
  size_bytes INTEGER,
  sha256 TEXT UNIQUE,
  status TEXT DEFAULT 'pending',   -- pending|queued|processing|done|error
  progress REAL DEFAULT 0,
  error TEXT,
  added_at TEXT DEFAULT CURRENT_TIMESTAMP,
  processed_at TEXT
);

CREATE TABLE segments (
  id INTEGER PRIMARY KEY,
  video_id INTEGER NOT NULL REFERENCES videos(id) ON DELETE CASCADE,
  start_ms INTEGER NOT NULL,
  end_ms INTEGER NOT NULL,
  text TEXT NOT NULL
);
CREATE INDEX idx_seg_video_time ON segments(video_id, start_ms);

CREATE VIRTUAL TABLE segments_fts USING fts5(
  text, content='segments', content_rowid='id',
  tokenize='unicode61 remove_diacritics 2'
);
-- (плюс триггеры INSERT/UPDATE/DELETE для синхронизации)

CREATE TABLE tags (
  id INTEGER PRIMARY KEY,
  parent_id INTEGER REFERENCES tags(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  color TEXT,
  UNIQUE(parent_id, name)
);

CREATE TABLE video_tags (
  video_id INTEGER REFERENCES videos(id) ON DELETE CASCADE,
  tag_id INTEGER REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (video_id, tag_id)
);

CREATE TABLE annotations (
  id INTEGER PRIMARY KEY,
  video_id INTEGER NOT NULL REFERENCES videos(id) ON DELETE CASCADE,
  start_ms INTEGER NOT NULL,
  end_ms INTEGER NOT NULL,
  label TEXT NOT NULL,
  color TEXT DEFAULT '#3b82f6',
  note TEXT,
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_ann_video ON annotations(video_id, start_ms);

CREATE TABLE segment_tags (
  segment_id INTEGER REFERENCES segments(id) ON DELETE CASCADE,
  tag_id INTEGER REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (segment_id, tag_id)
);

CREATE TABLE watched_folders (
  id INTEGER PRIMARY KEY,
  path TEXT UNIQUE NOT NULL,
  added_at TEXT DEFAULT CURRENT_TIMESTAMP
);
```

`PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL; PRAGMA foreign_keys=ON;`

## 5. API (FastAPI, префикс `/api`)

| Метод | Path | Назначение |
|---|---|---|
| GET | `/health` | проверка живости |
| GET | `/videos?folder=&tag_ids=&q=` | список файлов |
| POST | `/videos/scan` | просканировать папку `{path}` |
| POST | `/videos/enqueue` | добавить в очередь `{ids:[]}` или `{path}` |
| DELETE | `/videos/{id}` | удалить из индекса |
| POST | `/videos/{id}/reprocess` | переобработать |
| GET | `/videos/{id}/stream` | Range-стриминг видео |
| GET | `/videos/{id}/thumb` | превью-кадр |
| GET | `/videos/{id}/segments` | сегменты + метки |
| GET | `/search?q=` | полнотекстовый поиск |
| GET | `/tags/tree` | иерархия тегов |
| POST | `/tags` | создать `{parent_id?, name, color?}` |
| PATCH | `/tags/{id}` | переименовать / цвет |
| DELETE | `/tags/{id}` | удалить |
| POST | `/videos/{id}/tags` | назначить тег `{tag_id}` |
| DELETE | `/videos/{id}/tags/{tag_id}` | снять |
| POST | `/annotations` | создать метку |
| PATCH | `/annotations/{id}` | изменить |
| DELETE | `/annotations/{id}` | удалить |
| GET | `/events` | SSE: прогресс, изменения статусов |
| GET | `/folders` | список отслеживаемых папок |
| POST | `/folders` | добавить |
| DELETE | `/folders/{id}` | убрать |

Все ответы — JSON, ошибки — `{detail: string}` + HTTP-код.

## 6. Этапы (milestones)

Агент ведёт работу **итеративно**, после каждого этапа — рабочее состояние и коммит.

### M1. Скелет (1–2 дня)
- Electron main, запуск бэкенда, health-check, окно с заглушкой «Hello».
- Пустая БД, миграции.
- Dev-скрипты: `npm run dev` (Vite + uvicorn + electron).

**Готово, когда:** окно открывается, бэкенд стартует и отвечает на `/health`.

### M2. Библиотека и список файлов (2–3 дня)
- Сканирование папки, ffprobe-метаданные, дедупликация.
- Список файлов с сортировкой и статусами.
- Левая панель: дерево папок (таб «Файлы»).
- Добавление/удаление отслеживаемых папок.

**Готово, когда:** добавил папку → файлы появились в списке с длительностью.

### M3. Транскрипция (3–4 дня)
- ffmpeg-извлечение аудио, faster-whisper, запись сегментов.
- Воркер-процесс, очередь, статусы, SSE-прогресс.
- Отмена и повторная обработка.

**Готово, когда:** файл проходит путь `queued → processing → done`, сегменты видны в БД.

### M4. Поиск (1–2 дня)
- FTS5 + триггеры, `/search`, сниппеты, подсветка.
- Поле поиска в toolbar, дебаунс, результаты.

**Готово, когда:** ввод слова из транскрипции возвращает файлы и таймкоды.

### M5. Предпросмотр и тайминги (2–3 дня)
- Видео-плеер, Range-стриминг.
- Панель таймингов с подсветкой активного сегмента.
- Клик по сегменту → seek.
- Таймлайн с фоновыми блоками сегментов.

**Готово, когда:** открыл файл → вижу сегменты, клик → плеер прыгает на нужное время.

### M6. Теги (2–3 дня)
- Иерархия, CRUD, назначение файлам и сегментам.
- Левая панель: таб «Теги», drag&drop на файлы.
- Фильтрация списка по тегам.

**Готово, когда:** создал иерархию, назначил на файлы и сегменты, фильтр работает.

### M7. Метки (2–3 дня)
- Создание/редактирование/удаление.
- Отображение на таймлайне и в панели таймингов.
- Перетаскивание границ на таймлайне.

**Готово, когда:** выделил диапазон, сохранил метку, вижу её на таймлайне и в списке.

### M8. Упаковка (2–3 дня)
- PyInstaller `--onedir`, ffmpeg и модели внутрь.
- electron-builder → `.deb` и `.AppImage`.
- Проверка на чистой Ubuntu 24.04/26.04 VM (без Python, без ffmpeg).

**Готово, когда:** на чистой системе двойной клик по `.deb` ставит и запускает приложение, транскрипция работает.

### M9. Полировка (1–2 дня)
- Горячие клавиши, настройки, логи в `~/.local/share/VideoLessons/logs/`.
- Обработка ошибок, toast-уведомления.
- Тёмная тема.

**Готово, когда:** все критерии приёмки ниже выполнены.

## 7. Критерии приёмки

1. **Первый запуск:** на Ubuntu 26 без Python и ffmpeg — установка `.deb`, запуск, окно открывается < 5 с.
2. **Индексация:** пользователь добавляет папку с 3 видео → все три появляются в списке с корректной длительностью.
3. **Транскрипция:** видео на русском, 10 мин → обработано, сегменты в панели таймингов, средняя задержка < 15 с.
4. **Поиск:** запрос по слову из середины урока → в результатах этот файл, клик по сниппету → плеер открывает видео на нужной секунде.
5. **Тайминг:** клик по сегменту в панели → плавный seek, активный сегмент подсвечивается при воспроизведении и автопрокручивается.
6. **Теги:** создана иерархия `Учёба / Математика / Производные`, назначена на 2 файла, фильтр по «Математика» показывает оба файла.
7. **Метки:** создана метка 00:30–01:15 «важный пример», отображается на таймлайне и в панели, при клике — seek.
8. **Перезапуск:** после закрытия и открытия приложения всё состояние (файлы, теги, метки, размеры панелей) восстановлено.
9. **Остановка обработки:** закрытие окна во время транскрипции → процесс завершается ≤ 5 с, БД не повреждена, при следующем запуске файл в статусе `queued`.
10. **Нет сети:** после установки приложение не делает ни одного исходящего запроса (проверить через `ss -tp` / tcpdump).

## 8. Нефункциональные требования

- **RAM:** пиковое потребление ≤ 3 ГБ во время транскрипции `small`; ≤ 1.5 ГБ в покое.
- **CPU:** воркер не занимает больше 6 потоков; при активной транскрипции UI остаётся отзывчивым.
- **Диск:** временные WAV удаляются после обработки; логи ротируются (max 10 МБ × 5).
- **Безопасность:** бэкенд слушает только `127.0.0.1`, порт динамический; `contextIsolation: true`, `nodeIntegration: false`.
- **Логи:** файл `backend.log` с уровнем INFO; ошибки — WARNING/ERROR с traceback.
- **Локализация:** UI на русском; строки вынесены в `i18n/ru.json` (в будущем — английский).
- **Доступность:** контрастность ≥ 4.5:1, навигация с клавиатуры для основных сценариев.

## 9. Чего НЕ делать

- Не использовать `openai-whisper` (в 3-4 раза медленнее на CPU).
- Не запускать несколько параллельных Whisper-процессов.
- Не использовать `--onefile` PyInstaller (медленный старт, распаковка моделей при каждом запуске).
- Не хранить транскрипты в JSON-файлах рядом с видео — только БД.
- Не полагаться на фиксированный порт — только динамический выбор + передача бэкенду.
- Не блокировать event loop FastAPI вызовами `faster-whisper` — только через `ProcessPoolExecutor(max_workers=1)`.
- Не открывать внешние URL во встроенном браузере — только `shell.openExternal`.
- Не отключать sandbox Chromium в `.deb`.
